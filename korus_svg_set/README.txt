[KORUS 커스텀 영역 - SVG 방식 시안 세트]

■ 파일 구성 (시안별 2개씩)
  korus_v1.svg / korus_v1.html  : 시안 1 기본형
  korus_v2.svg / korus_v2.html  : 시안 2 제주풍경
  korus_v3.svg / korus_v3.html  : 시안 3 바로가기 8개
  korus_v4.svg / korus_v4.html  : 시안 4 슬로건 추가
  korus_v5.svg / korus_v5.html  : 시안 5 어우러짐

  .svg  → 깃허브에 올릴 그림 파일
  .html → 코러스 커스텀 영역에 붙여넣을 코드 (모두 4000바이트 이하)

■ 사용 방법
 1. 깃허브에 공개(Public) 저장소 "korus-test" 를 만들고 .svg 5개를 업로드
 2. .html 파일 안의 "GITHUB_ID" 를 본인 깃허브 아이디로 바꾸기
    (저장소 이름을 다르게 했다면 "korus-test" 도 바꾸기)
    예) https://cdn.jsdelivr.net/gh/GITHUB_ID/korus-test/korus_v5.svg
 3. 코러스 커스텀 영역 3곳에 붙여넣고 저장

■ 참고
 - 캐릭터(제록이)와 대학 로고는 학교 홈페이지 이미지를 그대로 불러옵니다.
 - 버튼은 투명 클릭 영역이 그림 위에 겹쳐져 있어 기존과 같은 메뉴로 이동합니다.
 - 글자를 바꾸려면 .svg 파일을 수정해서 다시 올려야 합니다.
 - 크롬·엣지에서 정상 표시됩니다. (사파리는 일부 표시 안 될 수 있음)
 - 외부 무료 서버는 테스트용으로만 쓰고, 실제 운영은 학교 서버에 올리는 것을 권장합니다.
